# 📚 קוראים ביחד! — Hebrew Reading App

Interactive Hebrew reading learning app for Israeli children (ages 5-7).

## Features
- 20 units: letters, nikud, syllables, words, sentences, stories
- Full audio feedback (Web Speech API + Web Audio tones)
- Open/closed sound distinction (בּ/ב, כּ/כ, פּ/פ)
- Swallowed letters (אות נבלעת) with visual + audio explanation
- Mascot with animations, coins, streak, badges
- PWA support — install to home screen
- iOS Safari compatible
- Works offline, no dependencies

## Run with Docker
```bash
chmod +x deploy.sh && ./deploy.sh
```
App: http://localhost:3001

## Open locally
Just open `index.html` in any browser.
